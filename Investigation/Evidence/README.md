# Investigation Evidence

This folder contains the original Windows Event Log (`.evtx`) files collected during the simulated security incident.

These files are provided so others can independently investigate the activity using tools such as Hayabusa and Hayabusa-Lens.

## Files

- `Security-before-clear.evtx` — Security event logs preserved before the simulated log-clearing activity.
- `Security-after-clear.evtx` — Security event logs collected after the log-clearing activity.
- `PowerShell.evtx` — PowerShell event logs collected during the simulation.

## Usage

Download the files and load them into Hayabusa or another compatible Windows Event Log analysis tool.

**Note:** These logs are from a controlled educational simulation, not a real-world security incident.
